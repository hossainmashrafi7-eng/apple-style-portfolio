# Mashrafi Hossain — Personal Website Demo

A responsive, Apple-inspired personal homepage for Mashrafi Hossain, a student at Moulvibazar Govt. College. Built with plain HTML, CSS, and JavaScript; no build step required.

## Preview locally

Open `index.html` in a browser. The Google Fonts connection is optional; the page has system fallbacks.

## Personalize it

- **Profile photo:** In `index.html`, find `portrait-placeholder`. Replace its contents with `<img class="portrait-image" src="images/mashrafi.jpg" alt="Mashrafi Hossain">`, create an `images` folder, and add your image. Add `.portrait-image{width:100%;height:100%;object-fit:cover;object-position:center}` to `styles.css`.
- **Gallery:** Replace each `.gallery-art` placeholder with an image, for example `<img src="images/memory-1.jpg" alt="Describe the photo">`, and style it with `width:100%;height:100%;object-fit:cover`.
- **Social links:** In `index.html`, replace the `#` in the Instagram, Facebook, and LinkedIn links with your profile URLs. Remove any links you don't want to share.
- **Bio:** Edit the introductory text in `index.html` to add any details you want to make public.

The social links and photos are placeholders for now. Review the personal information you choose to publish before making the site public.
